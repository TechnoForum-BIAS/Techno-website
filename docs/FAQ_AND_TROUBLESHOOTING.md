# 💡 Frequently Asked Questions & Troubleshooting Guide

This guide provides immediate answers and solutions to common questions and roadblocks that rookie interns encounter while working on the Technoforum codebase.

---

### Q1: What should I do if I get a CORS error when calling `/api` from React?
**Symptom**: `Access to fetch at 'http://localhost:5000/api/...' has been blocked by CORS policy`.  
**Solution**:
1. You do not need to call `http://localhost:5000` directly in frontend fetch calls! Simply call relative URLs like `/api/events` or `/api/inventory/items`.
2. The Vite development server in `client/vite.config.js` is already configured with a reverse proxy:
   ```javascript
   server: {
     port: 5173,
     proxy: {
       '/api': { target: 'http://localhost:5000', changeOrigin: true }
     }
   }
   ```
3. Ensure both the server (port 5000) and client (port 5173) are running.

### Q2: How do I test the backend if Supabase credentials are not set up yet?
**Symptom**: `Supabase credentials not found or placeholder values used`.  
**Solution**:
* You do **not** need to wait for Supabase access to start coding! The backend includes a built-in mock fallback for all routes (`auth`, `events`, `inventory`, `certificates`, `announcements`).
* You can test user login, adding inventory items, and issuing items right away.
* When your team lead provides the Supabase project URL and anon key, simply paste them into `server/.env`:
  ```env
  SUPABASE_URL=https://your-project.supabase.co
  SUPABASE_ANON_KEY=eyJhbGciOi...
  ```
  The server will automatically switch from mock mode to live PostgreSQL!

### Q3: Why is text drawn upside-down or in the wrong place on the PDF certificate?
**Symptom**: In `pdf-lib`, text appears at the bottom instead of the top, or coordinates don't match the web canvas.  
**Explanation & Solution**:
* Standard web browsers measure coordinates `(x, y)` starting from the **top-left corner** `(0, 0)`.
* PDF specifications measure coordinates starting from the **bottom-left corner** `(0, 0)`.
* To fix this, convert the `y` coordinate from top:
  ```javascript
  const { height } = firstPage.getSize();
  const pdfY = height - webY; // Converts top-left to PDF bottom-left coordinate
  ```
  Our utility `server/src/utils/pdfGenerator.js` handles this when `{ fromTop: true }` is passed.

### Q4: How does the AI Vision Scanner work without a paid API key?
**Symptom**: How can I test the component table photo recognition?  
**Solution**:
1. By default, `POST /api/inventory/scan-ai` uses an intelligent simulator that recognizes resistors, ultrasonic sensors, and Arduino boards with realistic confidence scores, allowing the frontend team to test UI card population and "Add to Cart" immediately.
2. If you want live Google Gemini AI recognition:
   - Grab a free Gemini API key from [Google AI Studio](https://aistudio.google.com/).
   - Add it to `server/.env`: `GEMINI_API_KEY=your_key_here`.

### Q5: How do I print barcode labels for hardware equipment?
**Symptom**: How do coordinators paste barcodes on extension cords and lab kits?  
**Solution**:
1. On the Inventory page, click on any unique serial number badge (e.g. `BIAS-EXT-001`).
2. A sticker label preview popup opens with the Code-128 barcode generated by `bwip-js`.
3. Click "Print Sticker Label" to print directly to a physical label printer or normal paper!

### Q6: How do I avoid Git merge conflicts with other intern groups?
**Golden Rules**:
1. **Never edit files outside your assigned domain**:
   - Group 1: Work inside `client/src/pages/HomePage.jsx`, `EventsPage.jsx`, `components/Hero3D.jsx`, `server/src/controllers/events.controller.js`.
   - Group 2: Work inside `client/src/pages/InventoryPage.jsx`, `server/src/controllers/inventory.controller.js`.
   - Group 3: Work inside `client/src/pages/CertificateStudioPage.jsx`, `CertificateVerifyPage.jsx`, `server/src/controllers/certificates.controller.js`.
2. Always run `git checkout develop && git pull origin develop` before starting work on your branch.
3. Keep commits atomic and descriptive.
